# Parcela

A workspace and local-environment organizer: stable named URLs, private runtime context,
and a CLI that wraps Process Compose. A separate project from rb-portless.

Primary: `https://shirabe.localhost`. Preview: `https://auth-shirabe.localhost`.
Flat names and tenants disabled by default. No silent browser-facing high-port fallback.

Implementation is in progress. See [the PRD](docs/PRD.md) and
[implementation status](docs/implementation.md) for verified coverage and limitations.
