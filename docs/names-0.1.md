# Product name candidates

**120 distinct candidates. None has been cleared for package, executable, repository, domain, or trademark availability.** These are naming ideas, not an availability report.

The vocabulary emphasizes separate places, paths, doors, branches, and connections. It should suit a named local environment, whether or not that environment has a Git branch. Command spellings below use ASCII; branding can retain accents/native script. Glosses are brief naming associations, not exhaustive dictionary definitions. Shortlisted borrowed words need native-speaker/connotation review before adoption.

## Shortlist

The product is a workspace/environment organizer, so a place or collection metaphor fits better than a name that only suggests a bridge/router. Current preference: **Niwa**, then **Hanare**, then **Sumika**. These are preferences, not a final name or availability result.

| Candidate | Why it fits the broader product | Tradeoff to check |
|---|---|---|
| **Niwa** | A garden: organize and tend several independent workspaces | Short-name conflicts and existing uses |
| **Hanare** | A detached annex: a complete working environment beside the primary home | Pronunciation and existing uses |
| **Sumika** | A dwelling: each workspace has a home for its services and state | Pronunciation and existing uses |
| **Glanta** | A clearing: a distinct working space | ASCII spelling omits Swedish ä |
| **Leku** | A place: broad enough for workspace organization, not only URLs | Existing brands/executables |
| **Nivaro** | Invented, readable, no Git/framework tie | No inherent meaning; connotation/collision checks still needed |

Naming shapes to compare: `hanare run -- bin/dev`, `zubi up`, `kajo url`, `varco doctor`, `nivaro share`. These are illustrative commands; no names or commands are installed by this document.

## Next naming decision

Pick roughly three to five candidates or a language/sound direction. Then check conflicts and connotations before changing the repository, executable, package names, or state directory. Branding is independent of the project-specific URLs: choosing Hanare does not change `shirabe.localhost` to a Hanare domain.
